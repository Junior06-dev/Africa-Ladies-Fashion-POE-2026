AFRICA LADIES FASHION

PROJECT OVERVIEW 
Africa Ladies Fashion is a website developed for a local women's fashion business located at Cosmo City Mall, Roodepoort, South Africa. 
The website provides customers with information about the business, its products, fashion gallery, location and contact details.

WEBSITE PURPOSE 
The purpose of the website is to provide an online presence for Africa Ladies Fashion and make useful information about the business easily accessable to customers. 
The website allows visitors to 
-Learn about Africa Ladies Fashion
-View the products and services offered by the business
-View examples of clothing and fashion accessories in the gallery 
-Find the location of the business 
-View the contact and store information
-Send an enquiry through the contact form 

TECHNOLOGIES USED 
The website was developed using:
-HTML5 
-CSS3
-Responsive web design
-Visual Studio Code 
-GitHub Pages 

WEBSITE PAGES 
HOME PAGE 
The home page introduces Africa Ladies Fashion and provides an overview of the business and its featured product categories.

ABOUT US PAGE 
The About Us page provides information about this business, including its history, mission, vision and reasons why customers may choose the business.
A google maps location map is also included to help visitors locate the business. 

PRODUCTS PAGE 
The products page presents the different catagories of products avaliable at Africa Ladies Fashion.
these include:
-Dresses 
-Tops 
-Jeans and trousers 
-Handbags 
-Shoes 
-Fashion Accessories 
A YouTube video is also embedded on the page. 

GALLERY PAGE 
The gallery page displays examples of women's clothing and Fashion accessories.
The gallery includes images of:
-Dresses 
-Tops 
-Jeans and trousers 
-Handbags 
-Shoes 
-Fashion Accessories

CONTACT US PAGE
The contact us page provides the businesses's store information and an enquiry form.
The form allows visitors to enter:
-Full name 
-Email address 
-Phone number 
-Subject 
-Message 

CSS STYLING AND RESPONSIVE DESIGN 
CSS was added to improve the appearance and usability of the website. 
The stylesheet is located in:
'CSS/style.css' 

The CSS was used to style the website's:
-Header
-Logo
-Navigation menu
-Main Content sections 
-Product sections 
-Image gallery
-Contact form 
-Footer 
-Embedded maps and videos 

Responsive CSS was also added so that the website can adjust to different screen sizes. A mobile media query was used to improve  the layout on smaller devices. This includes adjusting the navigation menu, logo size, images, forms, text sizes and embedded content.
The website was tested on a mobile phone to check that the layout adjusts correctly on a smaller screen.

JavaScript Enhancements and Search Engine Optimisation (SEO)
JavaScript was implemented to improve the website's functionality and provide visitors with a more interactive experience. This includes a dynamic product listing system with search, category filtering and sorting features, an interactive FAQ accordion, a gallery lightbox, scroll-triggered animations and a back-to-top button. SEO improvements were also made across the website by adding relevant page titles and meta descriptions, organising headings, including descriptive image alt text, improving internal navigation and ensuring the website is responsive across different screen sizes. Additionally, robots.txt and sitemap.xml files were created to help search engines discover and understand the website's pages.
